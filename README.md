# 🧮 Python Calculator

A simple GUI-based calculator built using **Python and Tkinter**. This project features a clean, button-based interface inspired by the classic iOS calculator, along with keyboard support for performing calculations.

## ✨ Features

- **Basic Arithmetic:** Addition, subtraction, multiplication, and division.
- **Percentage:** Convert numbers into percentages.
- **Sign Toggle:** Switch between positive and negative numbers.
- **Square Root:** Calculate the square root of a number.
- **Decimal Support:** Perform calculations with decimal numbers.
- **Clear Function:** Reset the calculator using the AC button.
- **Keyboard Support:** Perform calculations using your physical keyboard.
- **Error Handling:** Displays an error when attempting to divide by zero or calculate the square root of a negative number.

## ⌨️ Keyboard Shortcuts

| Key | Function |
|---|---|
| `0–9` | Enter numbers |
| `.` | Decimal point |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Percentage |
| `Enter` | Calculate result |
| `Backspace` | Delete last digit |
| `Esc` | Clear calculator |

## 🛠️ Technologies Used

- **Python 3** – Core programming language.
- **Tkinter** – GUI development.
- **Lambda Functions** – Handling button commands.
- **Keyboard Events** – Handling keyboard input using Tkinter event bindings.

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your system.
- Tkinter (usually included with standard Python installations).

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/python-calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-calculator
   ```

3. Run the application:

   ```bash
   python calculator.py
   ```
